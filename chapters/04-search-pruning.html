第4章 minimax 探索、メモ化、枝刈り

「残り \(d\) 回で必ず整列できるか」を再帰的に判定します。

4.1 概念的な再帰

比較不能対 \(\{a,b\}\) を選ぶと、子状態 \(P[a<b]\) と \(P[b<a]\) に分岐します。最悪時なので両方の子が残り \(d-1\) で可能である必要があり、アルゴリズム設計者は対を選べます。

\[ F(P,d)=\bigvee_{\{a,b\}\text{ incomparable}}\bigl(F(P_{a<b},d-1)\land F(P_{b<a},d-1)\bigr). \]

基底: \(e(P)=1\Rightarrow\mathrm{true}\)。\(e(P)>1\land d=0\Rightarrow\mathrm{false}\)。さらに \(e(P)>2^d\Rightarrow\mathrm{false}\)（情報下界）。

4.2 B0 / B1 / B2

定義。 \(B_0(P)=\lceil\log_2 e(P)\rceil\)。\(e(P)>1\) のとき \[ B_{k+1}(P)=1+\min_{\{a,b\}}\max\bigl(B_k(P[a<b]), B_k(P[b<a])\bigr) \] （min は比較不能対）。整列済みは 0。単調性 \(B_0\le B_1\le B_2\le\cdots\le S(P)\) が成り立つ（knowledge/definitions.md）。

No.009–015 ではこれらの棄却判定を独立oracleと照合しました。例: No.015 で 9,219 件一致（COMPUTATIONALLY_VERIFIED）。これは一般実装の完全証明ではありません。

4.3 早期 YES（e≤7）

上流の isEasilySortableLinExt と同条件を No.025 で Python に移植: \(e(P)\le 7\) かつ \(e(P)\le 2^{\min(d,3)}\) なら YES。n≤5 の適格ケースでoracleが常に真（COMPUTATIONALLY_VERIFIED）。一般補題の独立証明は本稿の範囲外で、上流コメント＝文献結果の移植です。

# 概念的擬似コード（No.019）
function feasible(P, d):
  e ← count_linear_extensions(P)
  if e = 1: return true
  if d = 0 or e > 2^d: return false
  if e ≤ 7 and e ≤ 2^min(d,3): return true   # optional
  key ← normalize(P) if isomorphic else P
  if (key,d) in memo: return memo[key,d]
  for each incomparable {a,b}:
    if feasible(P∪{a<b}, d-1) and feasible(P∪{b<a}, d-1):
      memo[key,d] ← true; return true
  memo[key,d] ← false; return false
資源上限: タイムアウトや計数キャッシュ上限で停止しても「整列不可能」の証明にはなりません。
